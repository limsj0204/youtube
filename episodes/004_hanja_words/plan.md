# 4화 기획안: 알고 보니 한자였던 우리말

## 제목 후보
1. **짐승은 원래 '중생'이었다** (추천: 가장 의외인 단어를 앞세움)
2. 사냥, 숭늉, 성냥의 공통점
3. 순우리말인 줄 알았는데 한자였던 말들

## 한 줄 소개
순우리말처럼 들리지만, 사전을 펼치면 한자가 숨어 있는 말들. 소리가 닳고, 모음이 바뀌고, 뜻까지 달라진 과정을 해체한다.

## 구성 (약 7분)

| 순서 | 장면 | 내용 | 화면 |
|---|---|---|---|
| 첫 장면 | hook | "짐승"이 원래 불교의 "중생(衆生)"이었다 | 큰 글자 '짐승', 아래에 衆生 |
| 1장 | 사전의 '어원' 칸 | 표준국어대사전에는 '어원' 칸이 있고, '＜'를 따라 옛 모습으로 거슬러 올라갈 수 있다. 예: 사냥 ＜ 산영 ＜ 山行 | 사전 화면처럼 꾸민 카드 |
| 2장 | 소리가 닳은 말 | 山行(산행) → 산영 → 사냥 / 熟冷(숙랭) → 슝농 → 숭늉 / 石硫黃(석류황) → 셕류황 → 성냥 (성냥은 원래 '유황'이었다) / 沈菜(침채) → … → 김치 | 단어 사슬 카드 (한자 → 옛말 → 지금) |
| 3장 | '도'가 '두'로 | 복숭아 도(桃) 삼형제: 앵도→앵두, 호도→호두, 자도→자두, 그리고 大棗 대조→대초→대추. 모두 '오'가 '우'로 바뀌었다 | 세 열매 그림 나란히 |
| 4장 | 우리 한자음이 아닌 말 | 白菜는 '백채'가 아니라 중국 발음에서 온 '배추'. 赤根菜도 '적근채'가 아니라 '시근채'를 거쳐 '시금치' | 우리 한자음과 실제 말 비교 카드 |
| 5장 | 뜻까지 바뀐 말 | 衆生: 살아 있는 모든 것 → 짐승 / 雪馬: 눈 위의 말 → 썰매 / 木綿 → 무명 | 뜻 변화 카드 |
| 6장 | 반전: 감자는 원래 고구마 | 甘藷(감저)는 원래 고구마를 가리킴 → 1824년 청나라에서 온 감자를 '북감저'라 부르며 이름이 섞임 → 김동인 소설 《감자》 속 감자는 고구마 → 제주도에서는 지금도 고구마가 '감저', 감자가 '지슬' → 정작 '고구마'라는 이름은 쓰시마 말에서 왔다 | 지도(청나라→조선, 쓰시마→부산), 연표 |
| 7장 | 설과 반론: 상추는 生菜? | 흔히 '生菜(생채)'에서 왔다고 하지만, 표준국어대사전은 어원을 적지 않았다 → 정설 아님 | 설 카드 + '사전에 없음' 도장 |
| 정리 | 오늘 해체한 단어 | 열두 단어 한 장으로 | 요약표 |

## 설과 반론이 들어가는 곳
- **상추 = 生菜?**: 널리 퍼진 설명 vs 사전에 어원 없음 (반론 근거 ✅)
- **감자**: '감자'라는 이름이 원래 고구마를 가리켰다는 반전 (위키백과 ⚠️ → 원 문헌 확인 필요)
- 나머지는 사전 근거가 분명해서 설이 갈리지 않음

## 쇼츠 아이디어 (홍보용, 25초 안팎)
- "짐승은 원래 중생이었다": 짐승 → 衆生 → 살아 있는 모든 것 → 짐승
- 또는 "김동인의 《감자》는 사실 고구마"

## 썸네일
- 큰 글자: **짐승 = 衆生?**
- 작은 줄: "알고 보니 한자였던 우리말"

## 조심할 점
- 옛한글(아래아 등)은 사전 사이트 전용 글꼴로만 보여서, 화면에는 읽을 수 있는 중간 형태만 쓴다.
- 소리가 바뀐 '원리'는 아직 국어학 자료로 확인하지 않았다. 확인 전까지는 "사전의 옛 형태를 보면 이렇게 달라졌다"고만 말한다.
- 감자와 고구마 이야기, 1824년 전래 연도는 위키백과로만 확인했다.
- 단어가 많아 늘어질 수 있으니, 장마다 대표 단어 하나를 크게 다루고 나머지는 짧게 묶는다.
