# 6화 기획안: '짤'은 무엇을 막았을까

근거: 국립국어원 우리말샘·표준국어대사전(✅), 한국어 위키백과 '디시인사이드'·'짤방'(⚠️). 자세한 내용은 research.md.

## 제목 후보
1. **'짤'은 사실 '잘림 방지'였다** (추천)
2. '짤'은 무엇을 잘랐을까
3. 짤의 탄생, 디시인사이드의 사진 규칙

## 한 줄 소개
매일 주고받는 '짤'. 잘라 낸 사진이라서 짤일까? 뿌리는 1999년 한 디지털카메라 사이트의 규칙, "사진 없는 글은 지운다"에 있었다.

## 구성 (약 4~5분)

| 순서 | 장면 | 내용 |
|---|---|---|
| 첫 장면 | 질문 | 짤, 움짤, 웃짤… 그런데 짤은 '잘라 낸 사진'이라서 짤일까? → 아닙니다. '잘림 방지'의 줄임말 |
| 1장 | 사전 속 짤 | 우리말샘: 짤 ← 짤방 ← '잘림 방지'. 원어는 **짤(고유어) + 防(막을 방)**, 반은 우리말 반은 한자. 그런데 표준어는 '짤리다'가 아니라 '잘리다' → 뿌리부터 비표준어 |
| 2장 | 디지털카메라 사이트의 규칙 | 1999년 10월 'Digital Camera Inside' 개설 → 사진 올리는 게시판이라 이름도 '갤러리' → 글에 사진이 꼭 있어야 했고, 신고 사유에 '사진 없음' |
| 3장 | 짤방의 탄생 | 2002년 후반부터, 글이 지워지지 않게 아무 관계없는 사진을 붙임 = 짤림 방지 사진 = 짤방 |
| 4장 | 짤방에서 짤로 | 뜻이 희석되어 '재미있는 사진'으로, 말도 줄어 '짤'. 웃짤, 움짤, 혐짤로 가지 치기. 2016년 신문 용례가 사전(우리말샘)에 실림: "짤 한 장으로 스타덤" |
| 덤 | 북한어 '짤방' | 북한에서는 '짤방'이 물방울이 똑 떨어지는 소리 |
| 정리 | | 잘림 방지 → 짤방 → 짤 |

## 설과 반론
- 근거 있는 경쟁 설은 찾지 못함 → 첫 장면의 "잘라 낸 사진?"은 **시청자가 떠올릴 만한 질문**으로만 쓰고 바로 사전 근거로 답함
- 정확히 누가 처음 썼는지는 자료가 없다는 점을 밝힘

## 화면
- 그림: 액자 속 사진(Fluent 'Framed picture'), 카메라(Fluent 'Camera'), 휴지통(Fluent 'Wastebasket'), '사진 없음' 신고 딱지는 직접 그림
- 디시인사이드 로고·화면 캡처는 쓰지 않음
- 연표: 1999 개설 → 2000 법인 → 2002 후반 짤방 → 2016 신문 용례

## 썸네일
- 큰 글자: **짤**
- 빨간 글자: 잘라 낸 사진?
- 흰 글자: 아니, '잘림 방지'
- 아래 띠: 디시인사이드에서 태어난 말

## 쇼츠 (20초 안팎)
- "짤은 무슨 뜻일까? → 잘림 방지 → 사진 없는 글을 지우던 규칙에서"

## 걱정되는 점
- 4~5분으로 짧은 편입니다. 길게 하려면 같은 곳에서 나온 말(갤러리의 '갤', 눈팅 등)을 덧붙일 수 있지만, 그 말들은 아직 근거를 확인하지 않았습니다.
- 디시인사이드는 논란이 많은 사이트라, 사이트에 대한 평가는 빼고 당시 규칙만 다룹니다.
